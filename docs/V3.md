# Identra v3 Platform

v3 completes the commercial platform surface: automation for non-API systems, full adapter catalog, public marketplace, air-gapped AI, certification/SoD, and multi-region foundations.

## New services

| Service | Port | Purpose |
|---------|------|---------|
| automation-factory | 8097 | Generate Playwright/Selenium/Robot/UiPath/Python packs |
| automation-runtime | 8098 | Execute automation packs on isolated workers (dry-run default) |
| certification-service | 8099 | Access certification campaigns + SoD evaluation |

## Adapter catalog (complete for v3)

Okta, SailPoint ISC, Entra, Saviynt, **Ping**, **Oracle IAM**, **IBM Verify**, **ForgeRock**, **MidPoint** (+ Identity Core).

## Air-gapped AI

```bash
IDENTRA_AI_AIRGAP_ENABLED=true
IDENTRA_AI_AIRGAP_ENDPOINT=http://llm.internal:8080
IDENTRA_AI_DEFAULT_PROVIDER=airgap
```

## Public marketplace

```bash
IDENTRA_MARKETPLACE_PUBLIC=true
# Public publish requires governance overall score >= 85
```

## Automation example

```bash
./gradlew :services:ai-gateway:bootRun &
./gradlew :services:governance-service:bootRun &
./gradlew :services:automation-factory:bootRun &

curl -s -X POST localhost:8097/v1/ai/automation-factory/runs \
  -H 'Content-Type: application/json' \
  -d '{
    "applicationName":"LegacyHR",
    "targetType":"BROWSER",
    "toolchain":"PLAYWRIGHT",
    "actions":["Create User","Disable User"]
  }'
```

## SoD example

```bash
curl -s -X POST localhost:8099/v1/certifications/sod/evaluate \
  -H 'Content-Type: application/json' \
  -d '{"entitlements":["payroll-admin","payroll-auditor"]}'
```
