# Identra v2 Platform

v2 expands Identra beyond the Fabric MVP into AI-assisted connector generation, bootstrap IAM, migration, and a private marketplace.

## Modules

| Service | Port | Purpose |
|---------|------|---------|
| ai-gateway | 8091 | Multi-provider LLM router (local template default) |
| governance-service | 8092 | Connector scorecards (coverage/security/compliance/…) |
| connector-factory | 8093 | AI connector generation wizard/API |
| identity-core-service | 8094 | Lightweight Bootstrap IAM (JML, RBAC, access request) |
| migration-service | 8095 | Cross-IAM export/transform/import dry-run engine |
| marketplace-service | 8096 | Private-tenant catalog for connectors/packs |

## New adapters

- `entra` — Microsoft Entra ID (dry-run)
- `saviynt` — Saviynt (dry-run)

Registered in `adapter-runtime` alongside Okta and SailPoint ISC.

## Example: generate a connector

```bash
# terminals
./gradlew :services:ai-gateway:bootRun &
./gradlew :services:governance-service:bootRun &
./gradlew :services:connector-factory:bootRun &

curl -s -X POST localhost:8093/v1/ai/connector-factory/runs \
  -H 'Content-Type: application/json' \
  -d '{
    "iamPlatform":"SailPoint ISC",
    "application":"SAP",
    "authenticationType":"REST",
    "actions":["Create User","Disable User","Delete User","Reset Password","Role Assignment"]
  }'
```

## Example: Identity Core joiner

```bash
./gradlew :services:identity-core-service:bootRun
curl -s -X POST localhost:8094/v1/core/identities \
  -H 'Content-Type: application/json' \
  -H 'X-Tenant-Id: 11111111-1111-1111-1111-111111111111' \
  -d '{"userName":"core.user","email":"core.user@example.com"}'
```

## Example: migration dry-run

```bash
curl -s -X POST localhost:8095/v1/migrations \
  -H 'Content-Type: application/json' \
  -d '{"sourceIam":"Okta","targetIam":"Entra","include":["roles","identitySchema"]}'
```

## AI safety

- Local provider redacts `password`/`api_key`/`Bearer` patterns
- Token budget enforced in AI Gateway
- Marketplace publish blocked when governance overall score &lt; 70
