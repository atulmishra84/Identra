# Development Standards

- ADR for every cross-cutting decision (`docs/adr/`)
- OpenAPI / protobuf first — no undocumented public endpoints
- Conventional commits; semver for adapters
- Feature flags for incomplete behavior
- Definition of Done: tests, OpenTelemetry hooks, runbook notes
- Vendor types must not appear outside `adapters/*`
- Trunk-based development with short-lived PRs
